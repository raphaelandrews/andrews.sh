who runs this site?

andrews. one webmaster, one text editor, too many GIFs.

why does it look like this?

because early-2000s personal websites were more fun than another dashboard. tables, pixel fonts, blinkies and a hit counter are the point.

is the Spotify thing real?

yes. the Worker talks to the Spotify Web API and the vinyl widgets show what is actually playing or what has been played recently. if nothing is playing, the widget says so.

why did Spotify stop working one day?

Spotify refresh tokens expire six months after authorization. when that happens the site shows an error box and the token has to be rotated with npm run auth.
